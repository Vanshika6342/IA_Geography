\section{Conclusion}

\subsection{Hypothesis 1 - Partially supported}

The obtained results vary completely from the expected values as although velocity is supposed to increase as channel efficiency increases, the results show the very opposite happening at all sites except for at Site 8, where the data corresponds to one another, yet still doesn't conform to the Bradshaw model, which states that the velocity is highest at the mouth. Channel efficiency does however support the Bradshaw Model as an overall increase is shown as one moves downstream.



\subsection{Hypothesis 2 - Partially supported}

As mentioned in the hypothesis, increase in the river's discharge does correlate to the channel width and channel depth to a certain extent. As mentioned before there is a moderate correlation between the width and the discharge with an r value of 0.595, however there is a weak correlation between depth and discharge with an r value of 0.333. Channel width corresponds to Bradshaw's Model where it increases as we move downstream as does channel. However discharge decreases as it moves downstream and therefore doesn't support the hypothesis or follow the Bradshaw Model.




\subsection{Hypothesis 3 - Fully supported}

Results obtained for the Bedload size completely support the hypothesis that they decrease in size as we move downstream, except for at Site 6, where it increases to 43.9mm from 38.3mm before dropping to 23.0mm at Site 7. More importantly, these results wholly support the Bradshaw Model.
